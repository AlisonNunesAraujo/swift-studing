# Nome do Projeto

App iOS desenvolvido em **Swift** com **SwiftUI**.

Projeto de estudos onde venho praticando a construção de interfaces nativas: criação de telas, navegação entre elas com `NavigationStack` e interação por meio de botões e ações. 
A ideia é evoluir o app conforme avanço nos estudos de iOS, adicionando novas telas e funcionalidades.

## Tecnologias
- Swift
- SwiftUI
- Xcode
